Dine Out Vancouver Interactive Map

This project focused on using GIS and web mapping to create an interactive tool for exploring restaurants participating in the Dine Out Vancouver Festival. Through spatial data processing, geocoding, and visualization, I transformed publicly available festival data into a geographic interface that allows users to explore options by location, price, and preferences.

Objectives

  • Transform publicly available festival data into a clean, structured spatial dataset.
  • Improve user experience by enabling geographic exploration and filtering of restaurant options.
  • Apply GIS and web mapping techniques to create a fast, mobile-friendly interactive map.

Approach

  • Data collection & processing:
    • Aggregated restaurant details, menus, and pricing from publicly available festival pages.
    • Cleaned and structured the data using Python for spatial processing.
  • Geocoding & data enrichment:
    • Converted addresses into spatial coordinates using OpenStreetMap (Nominatim) and Google Geocoding services.
    • Retrieved current restaurant ratings using the Google Places API and joined them to the spatial dataset.
  • Web mapping & interface design:
    • Exported processed data to GeoJSON for efficient rendering.
    • Built an interactive map with filters for price, cuisine, menu type, and rating.
    • Designed the interface for fast performance and usability on desktop and mobile.

Results

The project demonstrates how GIS, geocoding, and web technologies can be combined to transform static web data into intuitive spatial tools. The map was featured in the Georgia Straight, showcasing its value as an applied GIS project for public engagement.
